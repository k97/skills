## Gate 3 — hygiene pass

Adapts the `reclaude` progressive-disclosure refactoring workflow for agent memory files.

## Scope

These gates are the _detective_ half of the guidelines they adapt. The _preventive_ half belongs in the project's own agent memory file, always-on — which is what Gate 3 installs as the coding-guardrails rule. This skill checks compliance at the cycle boundaries; it does not replace the always-on rules.
